# 01 — Project Overview ☁️

## From virtualization to private cloud

This project was carried out as part of my summer internship at **Maroc DataCenter (MDC)**.

The objective was to design and implement an automated private cloud infrastructure using VMware technologies, exploring how virtualization, centralized management, shared storage and automation can work together.

The environment was deployed using nested virtualization, providing a practical setting for experimenting with infrastructure management and automation.

## 🎯 Project objectives

The main objectives documented in the project were:

- Install and configure VMware ESXi hypervisors.
- Deploy vCenter for centralized infrastructure management.
- Implement shared storage using TrueNAS.
- Configure network services, including DNS and NTP.
- Integrate Veeam Backup & Replication.
- Automate virtual machine provisioning using Ansible.
- Monitor infrastructure performance and availability using PRTG.
- Integrate Wazuh for security monitoring.

## 🏗️ Main technologies

| Technology | Role |
|---|---|
| VMware ESXi | Virtualization |
| VMware vCenter | Centralized management |
| TrueNAS | Shared storage |
| Ansible | Infrastructure automation |
| Veeam | Backup and recovery |
| PRTG | Infrastructure monitoring |
| Wazuh | Security monitoring |
